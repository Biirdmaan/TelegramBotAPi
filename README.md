# Telegram Bot CSV Downloader

A Python client for interacting with the WalletX Solana Bot to download CSV files.

## Setup

1. Install requirements:

```bash
pip install -r requirements.txt
```

2. Create a `.env` file with your Telegram API token:

```bash
TELEGRAM_API_TOKEN=your_api_token
```

3. Run the script:

```bash
python main.py
```

## Usage

The script will download the CSV files from the WalletX Solana Bot and save them to the `csv` directory.
